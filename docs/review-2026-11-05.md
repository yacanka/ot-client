## Tasarım ve uyumluluk

- Yeni çalışma bağımlılığı, API katmanı veya framework eklenmedi. OT uç noktaları, form alanları, iptal davranışı ve dosya adlandırması korundu.
- Parola biçimi hâlâ Windows DPAPI ile korunan `REG_BINARY`. `Settings` JSON'una geriye dönük okunabilen `password_binding` metadata alanı eklendi; eski kayıtlar destekleniyor. Özet düz metin paroladan değil şifreli veriden hesaplanıyor.
- Güvenlik nedeniyle bozuk yapılandırmada veya bağlantı/parola eşleşmesi bozulduğunda parolayı yeniden girmek gerekiyor. Eski şifreli kayıt otomatik silinmiyor. Eski uygulama sürümleri yeni eşleşme denetimini uygulamaz.
- Raporların atomik yazımı, mevcut liste dışa aktarımıyla aynı dosya yazma yardımcısını kullanıyor. Böylece iki akışın hata davranışı aynı kalıyor.
- HTTP ve TLS doğrulamasını kapatma seçenekleri mevcut açık kullanıcı tercihleri olarak korundu; TLS doğrulaması varsayılan olarak açık.
