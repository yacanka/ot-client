# Storage tab and document folders implementation plan

**Goal:** Separate local storage settings from connection settings and support optional per-document folders.

**Approved decisions:** Navigation is Belgeler → Depolama → Bağlantı. Folder mode defaults off, folder template defaults to `{numara}`, matching defaults to `exact`. Exact/contains matching is case-insensitive and limited to immediate children. Exact matches win; multiple candidates skip that document with a warning and continue. No existing-file overwrite/skip setting or client API changes; retain SHA comparison and atomic updates.

**Constraints:** Python 3.10+, Tkinter, no new dependencies. Preserve the user's existing edits and typed template controls. Keep global settings save/start/test/close semantics and independent registry recovery. Work in the supplied checkout without staging or committing unrelated edits.

## Interfaces

- `SettingsValidationError(field, message)` extends `ValueError` for UI routing.
- `AppSettings` adds `document_subfolder_enabled`, `document_subfolder_format`, `document_subfolder_match`.
- Both settings views expose `read_settings(base=None)`, `set_status`, `focus_field`, `mark_saved`, `set_busy`; each reads only fields it owns.
- `resolve_document_folder(output_dir, document, folder_format, match='exact') -> Path`; `FolderAmbiguityError` is a recoverable document outcome.
- Worker status `folder_ambiguous` maps to “Klasör belirsiz”, belongs to problems/retry, never success.

## Verification focus

- Cross-tab unsaved edits, save errors, close/start/test and unchanged saved queues.
- Disabled unfinished folder templates, legacy settings, corrupt independent fields.
- Exact/contains ambiguity, unsafe matched links, file/directory conflicts and sanitized metadata.
- Same filenames in different/shared folders; old paths cleared when a row is skipped.
- Real Tk minimum-window layout, error field focus and conditional busy-state restoration.
